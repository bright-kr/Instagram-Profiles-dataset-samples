이 **Instagram Profiles Dataset Sample**에는 **1,556개 레코드**가 포함되어 있으며, **Bright Data API**를 사용해 추출되었습니다.

## 데이터 포인트

| 필드 이름 | 설명 |
|------------|-------------|
| `account` | Instagram 계정의 사용자 이름입니다. |
| `fbid` | Instagram 계정과 연결된 Facebook ID입니다. |
| `id` | Instagram 계정의 고유 식별자입니다. |
| `followers` | 해당 계정의 팔로워 수입니다. |
| `posts_count` | 해당 계정이 작성한 총 게시물 수입니다. |
| `is_business_account` | 해당 계정이 비즈니스 계정인지 여부를 나타냅니다. |
| `is_professional_account` | 해당 계정이 프로페셔널 계정인지 여부를 나타냅니다. |
| `is_verified` | 해당 계정이 Instagram에서 인증되었는지 여부를 나타냅니다. |
| `avg_engagement` | 계정 게시물의 평균 참여율입니다. |
| `external_url` | 계정 bio에 연결된 외부 URL입니다. |
| `biography` | 계정 프로필의 자기소개 섹션입니다. |
| `business_category_name` | 계정이 비즈니스 계정인 경우의 비즈니스 카테고리 이름입니다. |
| `category_name` | 프로필과 연결된 일반 카테고리 이름입니다. |
| `post_hashtags` | 계정 게시물에 사용된 해시태그입니다. |
| `following` | 해당 프로필이 팔로우하는 계정 수입니다. |
| `posts` | 해당 계정이 작성한 게시물의 세부 정보입니다. |
| `profile_image_link` | 프로필 이미지의 URL 링크입니다. |
| `profile_url` | Instagram 프로필의 URL 링크입니다. |
| `profile_name` | Instagram 프로필의 표시 이름입니다. |
| `highlights_count` | 프로필의 스토리 하이라이트 수입니다. |
| `highlights` | 프로필의 스토리 하이라이트 세부 정보입니다. |
| `full_name` | 계정 소유자의 전체 이름입니다. |
| `is_private` | 해당 프로필이 비공개인지 여부를 나타냅니다. |
| `bio_hashtags` | 프로필 자기소개에 포함된 해시태그입니다. |
| `url` | 프로필 자기소개 섹션의 URL입니다. |
| `is_joined_recently` | 해당 계정이 최근에 생성되었는지 여부를 나타냅니다. |
| `has_channel` | 해당 계정에 IGTV 채널이 있는지 여부를 나타냅니다. |
| `partner_id` | 해당 계정의 비즈니스 파트너와 연결된 ID입니다. |
| `business_address` | 계정이 비즈니스 계정인 경우의 비즈니스 주소입니다. |
| `related_accounts` | 프로필과 관련 있거나 유사한 계정입니다. |
| `email_address` | 해당 계정과 연결된 이메일 주소입니다. |
| `external_url_title` | 외부 URL의 제목 또는 설명입니다. |


## 활용 사례

### 1. 소셜 미디어 인플루언서 분석
팔로워 수, 참여율, 콘텐츠 카테고리를 검토하여 잠재적인 인플루언서를 식별하고 분석합니다.

### 2. 시장 조사 및 트렌드 분석
프로필 데이터를 사용해 시장 트렌드를 추적하고, 소비자 행동을 이해하며, 제품 포지셔닝 전략을 개선합니다.

### 3. 경쟁사 벤치마킹
경쟁사의 Instagram 존재감, 콘텐츠 전략, 오디언스 참여도를 분석하여 벤치마킹합니다.
